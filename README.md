# 📚 StudyForge

A study assistant that turns your notes or a PDF into flashcards, a multiple-choice quiz, and a day-by-day study plan — with no AI API, no API key, and no internet dependency once loaded.

## Features
- PDF or pasted text input (extracted client-side with PDF.js)
- Automatic flashcard generation using keyword-frequency scoring and cloze deletion
- Flip-card review mode with "Got it" / "Still learning" tracking
- Auto-generated multiple-choice quiz built from the same flashcards
- Study plan generator based on days until your exam

## Running it
No installation needed. Open `index.html` in any modern browser, paste your notes, and click "Generate Flashcards."

## Disclaimer
Built to demonstrate practical text-processing and algorithm design — a heuristic system, not a language model.
